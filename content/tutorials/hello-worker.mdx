# 1. Hello worker

In this tutorial, an application authenticates to Core, reports its identity, and
appears in the Workers view. You need a [running Core](/docs/start/run-the-core)
and a worker token.

## Set the connection values

Provide these values through your shell, service manager, or secret store:

```dotenv
SYNAPSYS_CORE_URL=http://localhost:8080
SYNAPSYS_CORE_TOKEN=replace-with-your-worker-token
```

<Tabs groupId="connection">
<TabItem value="spring-boot" label="Spring Boot">

Add the [Maven Central dependency](/manuals/spring-boot/install), then configure:

```yaml title="application.yaml"
spring:
  application:
    name: hello-worker

synapsys:
  core-url: ${SYNAPSYS_CORE_URL}
  core-token: ${SYNAPSYS_CORE_TOKEN}
```

Start the application. The starter owns the heartbeat lifecycle.

</TabItem>
<TabItem value="nodejs" label="Node.js">

Install `@synapsys-io/sdk`, then:

```js title="app.js"
const { Synapsys } = require('@synapsys-io/sdk');

const synapsys = new Synapsys({ workerName: 'hello-worker' });
synapsys.start();
```

Run `node app.js`. The SDK reads the Core URL and token from the environment.

</TabItem>
<TabItem value="raw-api" label="Raw API">

Send a single authenticated heartbeat:

```bash
curl --request POST 'http://localhost:8080/api/v1/workers/heartbeat' \
  --header "Authorization: Bearer ${SYNAPSYS_CORE_TOKEN}" \
  --header 'Content-Type: application/json' \
  --data '{"workerName":"hello-worker","framework":"unknown","heartbeatInterval":5,"processes":[]}'
```

An empty `processes` array is valid. A real client repeats the request on the stated
interval; see [the Raw API loop](/manuals/raw-api/the-heartbeat-loop).

</TabItem>
</Tabs>

## Verify it

Sign in to Core and open **Workers**. `hello-worker` should appear after the first
successful heartbeat. Stop the application and it becomes inactive after Core no
longer receives its heartbeat.

There was no registration request: the authenticated heartbeat both introduces and
renews the worker. Keep `workerName` stable across restarts so Core recognises the
same application.
